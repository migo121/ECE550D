# PC3 - Register File
**Name:** Jasper Huang  
**NetID:** wh204  
## Design Implementation

This project implements a **32-register, 32-bit register file** with **two read ports** and **one write port**.

The register file uses a 1024-bit wire, `reg_wire`, to organize the outputs of all 32 registers. Each register occupies a 32-bit section of this wire. Register 0 is connected directly to `32'b0`, so it always reads as zero regardless of any attempted write.

Registers 1 through 31 are instantiated using a `generate for` block. Each 32-bit register is constructed from D flip-flops and receives the same `data_writeReg` input. A register is updated only when its individual enable signal is asserted on the positive edge of the clock.

A **5-to-32 decoder** is used to convert the 5-bit register address into a 32-bit one-hot signal. Three decoder instances are used:

- One decoder selects the register to write.
- One decoder selects the register for read port A.
- One decoder selects the register for read port B.

The write enable for each register is generated by combining the corresponding `write_select` bit with `ctrl_writeEnable`:

`reg_enable[i] = write_select[i] & ctrl_writeEnable`

Therefore, only the register selected by `ctrl_writeReg` can be modified during a write operation.

The two read ports are implemented independently using tri-state outputs. A `generate for` block connects every register to each read bus. The corresponding decoder output determines which register drives `data_readRegA` or `data_readRegB`. Registers that are not selected output high impedance (`32'bz`) to the read bus.

The `ctrl_reset` signal is connected to the clear input of all D flip-flops. When reset is asserted, all writable registers are asynchronously cleared to zero.

## Module Descriptions

### `regfile`

Top-level module that contains the 32 registers, write-selection logic, and two independent read ports.

### `decoder`

Implements a 5-to-32 one-hot decoder used to select one of the 32 registers for reading or writing.

### `register`

Implements a 32-bit register using 32 D flip-flops with clock, enable, and clear inputs.

### `dffe_ref`

Implements a one-bit positive-edge-triggered D flip-flop with an enable signal and asynchronous clear.
